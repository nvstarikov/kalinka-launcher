# Как помочь Калинка.Лаунчер

Спасибо, что хочешь сделать проект лучше! Вот все способы.

---

## 🐛 Сообщить об ошибке

1. Проверь, нет ли уже [открытого Issue](https://github.com/nvstarikov/kalinka-launcher/issues)
2. Если нет — создай новый через шаблон **🐛 Баг-репорт**
3. Опиши подробно:
   - Что делал (шаги)
   - Что ожидал увидеть
   - Что получил на самом деле
   - Версия лаунчера (видна в футере окна)
   - Версия Windows (10 или 11)
4. **Приложи логи**, если есть и отправь через лаунчер:
   - Файл: `%APPDATA%\stargrad-launcher\logs\launcher.log`
   - Открой проводник → вставь путь в адресную строку → Enter
   - Прикрепи последние 50–100 строк

> Чем подробнее описание — тем быстрее починим.

---

## 💡 Предложить идею

Есть мысль, как улучшить лаунчер?

1. Создай Issue через шаблон **💡 Предложение**
2. Опиши:
   - **Что** хочешь добавить
   - **Зачем** это нужно (какую задачу решает)
   - **Как** это может выглядеть (по желанию — скетч, скриншот)

Мы читаем всё. Даже если не реализуем сразу — идея останется в бэклоге.

---

## 📖 Улучшить документацию

Нашёл неточность в README, опечатку, или хочешь дополнить инструкцию?

1. Нажми **Fork** (справа сверху)
2. В своём форке отредактируй `README.md` (карандаш справа)
3. **Commit changes** в форке
4. Вернись в оригинальный репозиторий → **Pull requests → New pull request**
5. Опиши, что изменил, и создай PR

Правила для PR:
- Одна правка — один PR
- Коммит-сообщение в формате: `docs: исправлена опечатка в разделе Установка`
- Никаких массовых реформатов «ради красоты» — только по делу
