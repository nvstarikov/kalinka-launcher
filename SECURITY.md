# Политика безопасности

## Поддерживаемые версии

Актуальные обновления безопасности выпускаются только для последней
версии лаунчера.

| Версия | Поддержка |
|--------|-----------|
| 1.0.x  | ✅ |

Если у тебя старая версия — обновись через лаунчер (обновление
приходит автоматически при запуске).

---

## 🛡️ Сообщить об уязвимости

**НЕ создавай публичный Issue для уязвимостей** — это может навредить
пользователям до выхода патча.

### Как сообщить правильно

**Вариант 1 — через GitHub (рекомендуется):**

1. Перейди на вкладку **Security** репозитория
2. Нажми **Report a vulnerability**
3. Опиши:
   - Тип уязвимости
   - Шаги воспроизведения
   - Возможное влияние
   - Предлагаемое решение (если есть)

**Вариант 2 — через лаунчер:**
- (иконка "?") Обращение в техподдержку

Напиши на **support@stargrd.ru** с темой: Security версия 1.х.х

### Что мы обещаем

- Подтвердим получение в течение **48 часов**
- Держим тебя в курсе статуса исправления
- Укажем тебя в списке благодарностей (если не против)

---

## 🚫 Что НЕ считается уязвимостью

- Отсутствие цифровой подписи `.exe` (планируется в будущих релизах)
- Сообщения антивируса на неподписанные сборки (нормально для инди-проектов)
- Требование прав администратора при установке (архитектурное решение)
- Отсутствие поддержки старых версий Windows (Vista, 7, 8)

---

## 🔐 Что мы делаем для безопасности

- Все файлы скачиваются только с официального сервера `stargrd.ru`
- HTTPS для всех соединений
- Проверка целостности обновлений
- Никакого сбора личных данных пользователей
- Логи содержат только техническую информацию (ошибки, версии)
